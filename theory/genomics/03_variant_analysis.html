GENOMICS · CHAPTER 03

Genomic Variant Analysis

Raw sequencing read에서 신뢰할 수 있는 variant를 찾는 과정

Learning Objectives1. Workflow2. Raw Data QC3. Alignment4. BAM Processing5. Variant Calling6. Variant Types7. Filtering8. Annotation9. ToolsSummary & Check

Learning Objectives

  • FASTQ에서 annotated VCF까지의 분석 흐름을 설명할 수 있다.
  • Germline과 somatic variant calling의 설계 차이를 이해한다.
  • 주요 variant type과 filtering 지표를 구분할 수 있다.
  • Variant annotation이 제공하는 정보와 한계를 설명할 수 있다.

1. Overview of the Workflow

FASTQ→QC→Alignment→BAM/CRAM→Variant Calling→VCF→Filtering→Annotation

각 단계는 독립적이지 않습니다. 예를 들어 낮은 base quality와 잘못된 alignment는 variant caller의 false positive로 이어질 수 있습니다. 따라서 최종 VCF만 확인하는 것이 아니라 upstream QC를 함께 검토해야 합니다.

2. Raw Data Quality Control

Per-base qualityRead 위치별 Phred score 분포를 확인합니다.
GC content예상 분포와 과도한 편향 여부를 확인합니다.
Adapter contentLibrary adapter가 read에 남아 있는지 확인합니다.

QC의 목적

QC는 좋은 sample과 나쁜 sample을 단순히 구분하는 과정이 아니라, 이후 분석에 영향을 줄 수 있는 기술적 특성을 파악하는 과정입니다. Trimming은 필요할 때만 적용하며, 무조건적인 trimming은 유용한 정보를 제거할 수 있습니다.

3. Read Alignment

Alignment는 sequencing read를 reference genome의 가장 적절한 위치에 배치하는 과정입니다.

개념의미
Mapped readReference의 특정 위치에 정렬된 read
Unmapped read충분히 신뢰할 수 있는 위치를 찾지 못한 read
Multi-mapped read반복서열 등으로 여러 위치에 정렬 가능한 read
Mapping quality선택된 정렬 위치가 맞을 가능성에 대한 신뢰도
CIGAR stringMatch, insertion, deletion 등 read-reference 관계
주의: Reference genome의 build와 contig 이름이 downstream annotation resource와 일치해야 합니다.

4. BAM Processing

Sort→Index→Duplicate marking→Recalibration→BAM QC
  • Sorting: Alignment를 genomic coordinate 순으로 정렬합니다.
  • Indexing: 특정 영역을 빠르게 조회할 수 있게 합니다.
  • Duplicate marking: PCR·optical duplicate 후보를 표시합니다.
  • BQSR: 알려진 변이와 기술적 요인을 이용해 base quality를 보정합니다.

사용하는 pipeline과 sequencing platform에 따라 일부 과정은 통합되거나 생략될 수 있습니다.

5. Variant Calling

분석목적주요 설계
Germline calling개인이 선천적으로 보유한 variant 탐색Haplotype 기반 calling, joint genotyping 가능
Somatic calling종양 또는 특정 세포집단에서 후천적으로 발생한 variant 탐색Tumor-normal paired 또는 tumor-only

Tumor-normal paired analysis

Tumor와 matched normal을 비교하면 germline variant와 개인 특이적 sequencing artifact를 효과적으로 구분할 수 있습니다. Tumor-only 분석에서는 panel of normals와 population database 의존도가 높아집니다.

Key point: 말초혈액 genomic DNA 자체를 분석하는 연구라면 일반적으로 germline variant 분석으로 기술해야 합니다. 종양 또는 clonal population과 비교하지 않고 somatic variant라고 부르면 분석 목적과 맞지 않을 수 있습니다.

6. Variant Types

SNV한 개 염기의 치환입니다.
Indel짧은 염기서열의 삽입 또는 결실입니다.
CNV유전체 구간의 copy number 증감입니다.
SV큰 결실, 중복, 역위 또는 전좌입니다.
Gene fusion두 유전자 또는 유전체 영역의 비정상 결합입니다.
Mitochondrial variant미토콘드리아 유전체의 변이와 heteroplasmy입니다.

Variant type마다 적절한 caller와 검증 전략이 다르며, 하나의 SNV caller로 모든 변이를 검출할 수 없습니다.

7. Variant Filtering

Metric확인하는 내용
DP / depth해당 위치를 지지하는 전체 read 수
ADReference 및 alternative allele을 지지하는 read 수
VAFAlternative allele read의 비율
Base qualityVariant base 판독의 신뢰도
Mapping qualityVariant-supporting read 정렬 위치의 신뢰도
Strand biasVariant evidence가 한 방향 read에 편중되는지 여부
주의: 모든 연구에 적용되는 하나의 절대 cutoff는 없습니다. Platform, depth, 시료 순도, variant type과 분석 목적에 따라 기준을 정해야 합니다.

8. Variant Annotation

Annotation은 variant에 유전자, transcript, 단백질 변화, 인구집단 빈도, 질환 및 기능 예측 정보를 연결합니다.

Genomic coordinate→Gene / transcript→Protein consequence→Population frequency→Disease evidence
Transcript 주의: 동일한 genomic variant도 선택한 transcript에 따라 coding consequence가 달라질 수 있습니다. Genome build와 transcript version을 함께 기록해야 합니다.

도구 이름보다 중요한 것은 각 단계가 해결하는 문제와 입력·출력 데이터의 의미를 이해하는 것입니다.

Key Takeaways

  • Variant quality는 sequencing부터 annotation까지 모든 단계의 영향을 받습니다.
  • Germline과 somatic 분석은 생물학적 질문과 비교 설계가 다릅니다.
  • Variant type별로 다른 검출 알고리즘이 필요합니다.
  • Filtering 기준은 연구 목적과 데이터 특성에 맞게 설정해야 합니다.
