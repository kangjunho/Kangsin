Systems & Infrastructure

분석환경을 안정적이고 재현 가능하게 설계하고 운영하는 단계형 로드맵

What Is a Bioinformatics System?

생물정보학 시스템은 고성능 컴퓨터 한 대를 의미하지 않습니다. 연구자가 접속하는 환경, 분석을 실행하는 compute resource, software version, 원자료와 결과를 보관하는 storage, backup, security 및 monitoring이 함께 작동하는 구조입니다.

Researcher · Browser · RStudio · Terminal · Notebook
Workflow · Scheduler · Containers · Conda Environments
Workstation · Server · HPC · GPU · Cloud Compute
Local Storage · NAS · Archive · Backup · Access Control
System Building이 답하는 질문: 분석을 어디에서, 어떤 software environment로 실행하고, 데이터를 어떻게 안전하게 보존하며, 같은 분석을 다시 실행할 수 있게 만들 것인가?

Six-stage Build Map

각 단계는 앞 단계의 결정에 영향을 받습니다. 장비를 먼저 구매하기보다 데이터 규모, 분석유형, 사용자 수와 보안요건을 정의한 뒤 architecture를 설계합니다.

Architecture Planning

연구와 데이터 규모를 계산자원 요구사항으로 번역합니다.

  • Data type and annual growth
  • CPU, RAM, GPU and storage sizing
  • Workstation vs server vs HPC/cloud
  • User and collaboration model

Linux & Server

다중 사용자가 안전하게 접속하고 작업할 수 있는 기본 실행환경을 만듭니다.

  • Linux filesystem and shell
  • User, group and permissions
  • SSH and remote access
  • Process and resource monitoring

Storage & Data

원자료, 중간파일, 결과와 archive를 분리하고 데이터 수명주기를 관리합니다.

  • Local disk, RAID and NAS
  • Project folder convention
  • Metadata and provenance
  • Retention and archive policy

Software Environments

Package 충돌을 줄이고 분석환경을 다시 만들 수 있게 합니다.

  • R and Python libraries
  • Conda / mamba environments
  • Docker and Apptainer
  • Version pinning and lock files

Workflow & Compute

수작업 명령을 재현 가능한 pipeline과 계산작업으로 전환합니다.

  • Shell and Git
  • Snakemake / Nextflow
  • Scheduler and parallel jobs
  • HPC, GPU and cloud execution

Security & Backup

민감자료 접근, 장애대응과 복구 가능성을 운영정책으로 관리합니다.

  • Least-privilege access
  • Encryption and audit logs
  • 3-2-1 backup strategy
  • Monitoring and disaster recovery

Design Principles

Start from workload장비사양보다 분석유형, peak memory, 동시사용자와 데이터 증가량부터 계산합니다.
Separate data classesRaw, working, result, archive를 구분하고 서로 다른 보존정책을 적용합니다.
Make environments explicitPackage version, reference data와 container image를 분석코드와 함께 기록합니다.
Automate repeatable work반복 명령은 workflow로 정의하고 input·output·log를 추적합니다.
Design for failureDisk, server와 사용자는 실패할 수 있다는 전제로 backup과 recovery를 시험합니다.
Protect sensitive data사람 유전체와 임상정보에는 최소권한, 암호화, audit와 승인정책을 적용합니다.

Boundary with the Bioinformatics Hub

Bioinformatics

분석원리, 연구설계, 통계적 해석, database, 최신 방법론과 논문 리뷰를 다룹니다.

Systems & Infrastructure

실행환경, storage, server, container, workflow, security와 operation을 다룹니다.

예시: DESeq2의 negative binomial model과 결과 해석은 Bioinformatics 영역이고, DESeq2가 설치된 R environment를 container로 고정하고 server에서 workflow로 실행하는 방법은 Systems 영역입니다.
