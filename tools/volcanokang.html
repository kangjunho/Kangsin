R PACKAGE · v0.1.1

VolcanoKang

DEG 결과에서 Up·Down 유전자를 구분하고 Volcano plot을 생성하는 R 패키지

← R Tools 목록으로 돌아가기

1GitHub에서 바로 설치

권장 설치 방법입니다. GitHub 저장소의 packages/VolcanoKang 폴더에서 최신 패키지를 설치합니다.

options(timeout = 1200)
options(download.file.method = "libcurl")
Sys.setenv(R_DEFAULT_INTERNET_TIMEOUT = 1200)

if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes")
}

remotes::install_github(
  "kangjunho/Kangsin",
  subdir = "packages/VolcanoKang",
  dependencies = TRUE,
  upgrade = "never"
)

library(VolcanoKang)
packageVersion("VolcanoKang")
GitHub에 새 버전을 올린 뒤 다시 설치할 때는 위 코드의 install_github()에 force = TRUE를 추가하면 됩니다.

2파일을 내려받아 설치

기관 네트워크에서 GitHub 설치가 제한될 때 사용할 수 있는 방법입니다.

VolcanoKang v0.1.1 원본 v0.1.0 
package_file <- file.choose()  # .tar.gz 파일 선택
install.packages(package_file, repos = NULL, type = "source")
library(VolcanoKang)

v0.1.1은 순수 R 패키지(NeedsCompilation: no)이므로 일반적으로 Rtools가 필요하지 않습니다.

3입력 데이터

열 이름내용예시
gene표시할 Gene symbolTP53
log2FoldChange두 군 간 log2 fold change1.84
pvalue통계 검정의 p-value0.0003

4Volcano plot 생성

deg <- read.csv(file.choose(), check.names = FALSE)

# limma 결과처럼 열 이름이 다르면 먼저 변경합니다.
names(deg)[names(deg) == "Gene.symbol"] <- "gene"
names(deg)[names(deg) == "logFC"] <- "log2FoldChange"
names(deg)[names(deg) == "P.Value"] <- "pvalue"

volcano_plot <- generate_volcano_plot(
  data = deg,
  log2fc_cutoff = 1,
  pvalue_cutoff = 0.05,
  label_genes = TRUE,
  label_top_n = 20
)

volcano_plot

그림을 확인한 후 저장

ggplot2::ggsave(
  "volcano_plot.png",
  plot = volcano_plot,
  width = 10,
  height = 7,
  dpi = 300,
  bg = "white"
)

주요 인자

인자기본값설명
log2fc_cutoff1Up/Down 판정에 사용할 절대 log2FC 기준
pvalue_cutoff0.05통계적 유의성 기준
label_genesTRUE유의 유전자 라벨 표시 여부
label_top_n20p-value 순으로 표시할 최대 유전자 수
