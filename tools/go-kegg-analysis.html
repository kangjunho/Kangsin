3Gene symbol 준비

DEG 결과에서 Gene symbol 열을 선택합니다. 결측값과 중복값은 함수 내부에서 정리됩니다.

deg <- read.csv(file.choose(), check.names = FALSE)
names(deg)

# 실제 Gene symbol 열 이름으로 변경합니다.
gene_symbols <- deg$Gene.symbol

head(gene_symbols)
length(gene_symbols)
Up DEG와 Down DEG는 하나의 목록으로 섞지 말고 각각 분석하는 것이 좋습니다. GO·KEGG enrichment 자체에는 발현 방향 정보가 없기 때문입니다.

4GO·KEGG 분석

enrichment <- run_go_kegg(
  gene_symbols = gene_symbols,
  pvalue_cutoff = 0.05,
  qvalue_cutoff = 0.20
)

# Gene symbol → ENTREZ ID 변환 결과
head(enrichment$mapping)

# 분석 결과표 확인
go_table <- as.data.frame(enrichment$go)
kegg_table <- as.data.frame(enrichment$kegg)

View(go_table)
View(kegg_table)

5Dot plot 확인

go_plot <- plot_go(
  enrichment$go,
  show_category = 10
)

kegg_plot <- plot_kegg(
  enrichment$kegg,
  show_category = 10
)

go_plot
kegg_plot
