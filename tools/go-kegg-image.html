GO & KEGG Result Image

GO, KEGG 또는 STRING enrichment 결과를 dot plot으로 시각화

← R Tools 목록으로 돌아가기

1패키지 설치와 함수 불러오기

install.packages(c("ggplot2", "dplyr", "stringr"))

source(
  "https://raw.githubusercontent.com/kangjunho/Kangsin/main/assets/downloads/r-tools/GO_KEGG_Image.R"
)
GO_KEGG_Image.R 다운로드

2입력 결과표

함수에는 기능 설명, 유전자 수, FDR에 해당하는 세 열이 필요합니다. 열 이름은 함수 인자로 직접 지정할 수 있습니다.

예시 열 이름내용허용 예시
descriptionGO term 또는 pathway 이름Oxidative phosphorylation
count_in_network해당 기능에 포함된 유전자 수20 또는 20 of 8096
false_discovery_rateFDR0.00016

3Dot plot 생성

result_table <- read.csv(
  file.choose(),
  check.names = FALSE
)

names(result_table)
View(result_table)

enrichment_plot <- plot_enrichment_dot(
  data = result_table,
  description_col = "description",
  count_col = "count_in_network",
  fdr_col = "false_discovery_rate",
  top_n = 10,
  title = "GO Biological Process"
)

enrichment_plot
count_in_network가 20 of 8096처럼 문자로 되어 있어도 함수가 앞쪽의 유전자 수를 자동 추출합니다.

4확인 후 저장

ggplot2::ggsave(
  "GO_enrichment_dotplot.png",
  plot = enrichment_plot,
  width = 10,
  height = 7,
  dpi = 300,
  bg = "white"
)
