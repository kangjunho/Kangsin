Dimensional Reduction and Clustering

Step 05 / 08

통합된 scRNA-seq 데이터를 PCA로 요약하고, 세포 간 이웃 관계를 바탕으로 cluster를 구성한 뒤 UMAP에서 세포 집단의 구조를 확인합니다.

Part 1. Theoretical Background

A) PCA, neighbor graph, clustering과 UMAP의 관계

단계 역할 이번 분석의 설정
PCA 수천 개 유전자의 발현 변이를 소수의 principal component로 요약합니다. integrated assay에서 30개 PC 계산
FindNeighbors PCA 공간에서 각 세포의 이웃을 찾고 KNN/SNN graph를 생성합니다. PC 1~20 사용
FindClusters SNN graph에서 서로 밀접한 세포 community를 탐색합니다. Louvain, resolution 0.5
UMAP PCA 공간의 국소적 이웃 구조를 2차원에서 시각화합니다. PC 1~20 사용
핵심 개념
  • PCA는 neighbor graph와 clustering의 입력 공간입니다.
  • 실제 clustering은 UMAP 좌표가 아니라 PCA 기반 SNN graph에서 수행됩니다.
  • UMAP은 cluster 구조를 보기 쉽게 표현하는 시각화 결과입니다.

D) 사용할 PC 수 확인

Elbow plot은 PC가 추가될수록 설명력이 감소하는 지점을 확인하는 도구입니다. 이번 처리에서는 PC 1~20을 neighbor graph와 UMAP에 사용했습니다. 

ElbowPlot(
  integrated_obj,
  ndims = 30
)

초기 PC에서 설명력이 빠르게 감소한 뒤 완만해지는 구간을 확인하여 사용할 dims 범위를 검토합니다.

  • 기울기가 급격히 완만해지는 elbow 전후의 PC를 후보로 고려합니다.
  • PC 수가 너무 적으면 세부 세포 집단을 놓칠 수 있습니다.
  • PC 수가 너무 많으면 noise가 neighbor graph에 포함될 수 있습니다.
  • Elbow plot만으로 결정하지 말고 PC loading, cluster 안정성과 known marker를 함께 확인합니다.

E) 실제 처리 과정: neighbor graph와 clustering

이번 실습에서는 아래 코드를 다시 실행하지 않아도 됩니다.
저장된 객체에 PC 1~20 기반 neighbor graph와 resolution 0.5의 clustering 결과가 이미 포함되어 있습니다. 아래 코드는 실제 처리 과정을 이해하기 위한 참고용입니다. 
# PCA 공간에서 neighbor graph 생성
integrated_obj <- FindNeighbors(
  integrated_obj,
  dims = 1:20
)

# SNN graph 기반 clustering
integrated_obj <- FindClusters(
  integrated_obj,
  resolution = 0.5,
  random.seed = 1234
)
resolution 일반적인 경향
낮음 (예: 0.2) cluster 수가 적고 큰 세포 집단으로 묶이는 경향이 있습니다.
중간 (예: 0.5~0.8) 주요 세포 유형과 일부 세부 집단을 함께 구분할 수 있습니다.
높음 (예: 1.0 이상) cluster가 더 세분화되지만 과도한 분할 가능성도 증가합니다.

F) 실제 처리 과정: UMAP

UMAP도 이미 계산되어 있습니다. 아래 코드는 PC 1~20을 사용하여 현재 저장된 UMAP을 생성했던 실제 처리 과정입니다. 

# 참고용: 저장 객체에서는 재실행하지 않음
integrated_obj <- RunUMAP(
  integrated_obj,
  dims = 1:20,
  seed.use = 1234
)
주의: UMAP은 확률적 알고리즘이므로 같은 데이터라도 random seed나 패키지 버전이 달라지면 배치 방향과 세부 모양이 달라질 수 있습니다. UMAP의 모양이 조금 다르다고 해서 분석 결과가 틀린 것은 아닙니다.

여러 resolution을 비교할 때는 실습용 최종 객체를 덮어쓰지 않도록 별도의 임시 객체를 사용합니다.

resolution 선택 기준: cluster 수가 많아지는 것 자체가 좋은 결과는 아닙니다. known marker가 자연스럽게 구분되는지, 작은 cluster가 재현 가능한지, 조건 또는 샘플 하나에만 치우친 cluster가 있는지를 함께 확인합니다.

K) 다음 annotation 단계 준비

PCA, UMAP과 clustering은 integrated assay를 기준으로 수행하지만, marker gene의 실제 발현 확인과 differential expression은 RNA assay를 사용합니다. 

# 현재 cluster identity 확인
Idents(integrated_obj) <- "seurat_clusters"
levels(integrated_obj)

# marker 분석을 위해 RNA assay로 전환
DefaultAssay(integrated_obj) <- "RNA"

# RNA assay가 Assay5 형식이고 layer가 분리된 경우에만 결합
if (inherits(integrated_obj[["RNA"]], "Assay5")) {
  integrated_obj <- JoinLayers(
    integrated_obj,
    assay = "RNA"
  )
}

DefaultAssay(integrated_obj)
Layers(integrated_obj[["RNA"]])
중요: integrated assay에서 marker DEG를 계산하면 batch-corrected 값에 기반한 결과가 됩니다. Cell type annotation을 위한 marker 탐색은 원래 발현값이 보존된 RNA assay에서 수행합니다.
JoinLayers 오류를 피하는 이유

JoinLayers()는 Seurat v5의 Assay5 객체에 사용하는 함수입니다. 현재 RNA assay가 기존 Assay 형식이면 결합할 layer가 없으므로 실행하지 않아도 됩니다. 따라서 객체 유형을 먼저 확인한 뒤 필요한 경우에만 실행합니다.
