1R이란 무엇인가?

R은 데이터를 처리하고 통계적으로 분석하며, 분석 결과를 그래프로 표현할 수 있는 프로그래밍 언어이자 분석 실행 환경입니다.

생명정보학에서는 유전자 발현 분석, 차등발현 유전자 분석, 생존분석, 기능분석 등 다양한 연구에 R이 사용됩니다. 이번 교육에서는 GEO에서 공개된 microarray 데이터를 R로 불러와 분석합니다.

이번 과정에서 R이 하는 일

GEO 데이터 다운로드 임상정보 정리 발현값 전처리 DEG 분석 결과 시각화 GO·KEGG·GSEA
① R Console

R 명령어를 입력하고 실행 결과와 오류 메시지를 확인하는 공간입니다.

빨간색 > 기호

R이 새로운 명령을 입력받을 준비가 되었다는 의미입니다.

2RStudio란 무엇인가?

RStudio는 R 코드를 편리하게 작성하고 실행할 수 있도록 도와주는 통합개발환경(IDE)입니다.

코드 편집기, 실행 결과, 분석 중 생성된 데이터, 그래프와 파일을 하나의 화면에서 관리할 수 있습니다. RStudio는 R을 대신하는 프로그램이 아니라 설치된 R을 더 편리하게 사용하도록 도와주는 프로그램입니다.

중요: RStudio만 설치해서는 R 분석을 실행할 수 없습니다. 반드시 R을 먼저 설치한 다음 RStudio를 설치해야 합니다.

4Windows에서 R 설치하기

R 공식 다운로드

CRAN(The Comprehensive R Archive Network)의 공식 Windows 다운로드 페이지를 이용합니다.

Windows용 R 다운로드 CRAN 홈페이지
  1. 위의 Windows용 R 다운로드 버튼을 클릭합니다.
  2. 페이지 상단의 Download R-x.x.x for Windows 링크를 클릭합니다.
  3. 다운로드된 .exe 설치 파일을 실행합니다.
  4. 설치 언어를 선택하고 안내에 따라 진행합니다.
  5. 특별한 이유가 없다면 설치 위치와 구성 요소를 포함한 모든 항목을 기본값으로 유지합니다.
  6. 설치가 완료되면 Windows 시작 메뉴에서 R을 확인합니다.
권장 설정: 이 교육에서는 최신 정식 버전의 64-bit R을 사용합니다. R 버전 번호는 업데이트에 따라 달라질 수 있습니다.

5Windows에서 RStudio 설치하기

RStudio Desktop 공식 다운로드

RStudio는 Posit에서 개발합니다. 교육용으로 무료 RStudio Desktop을 설치합니다.

RStudio Desktop 다운로드 RStudio 소개
  1. R 설치가 완료되었는지 먼저 확인합니다.
  2. 위의 RStudio Desktop 다운로드 버튼을 클릭합니다.
  3. Windows용 RStudio 설치 파일을 다운로드합니다.
  4. 다운로드된 설치 파일을 실행합니다.
  5. 설치 위치 등은 기본값을 유지하고 설치를 완료합니다.
  6. Windows 시작 메뉴에서 RStudio를 실행합니다.
처음 실행했을 때 RStudio가 정상적으로 열리고 Console에 R 버전이 표시되면 R과 RStudio가 서로 연결된 것입니다.

6R과 RStudio를 쉽게 실행하도록 고정하기

설치가 끝나면 매번 설치 폴더를 찾아가지 않아도 되도록 작업표시줄에 고정하거나, 자주 사용하는 폴더에 바로가기를 복사해 둘 수 있습니다.

1) 시작 메뉴에서 프로그램 찾기

  1. 키보드의 Windows 키를 누르거나 화면 아래의 검색창을 클릭합니다.
  2. R을 검색합니다.
  3. 설치한 버전에 따라 R 4.6.1, R 4.5.1처럼 버전 번호가 포함된 프로그램이 표시됩니다.
  4. R-x.x.x-win.exe는 다운로드한 설치 파일이고, R x.x.x는 설치된 R을 실행하는 항목입니다. 두 항목을 혼동하지 않습니다.
  5. RStudio를 검색하면 RStudio 실행 항목도 같은 방법으로 찾을 수 있습니다.

2) 작업표시줄에 고정하기

  1. 검색 결과의 R x.x.x를 마우스 오른쪽 버튼으로 클릭합니다.
  2. 작업 표시줄에 고정을 선택합니다. 메뉴가 바로 보이지 않으면 더 보기를 먼저 선택합니다.
  3. RStudio도 동일한 방법으로 작업표시줄에 고정합니다.
  4. 화면 아래 작업표시줄에 R과 RStudio 아이콘이 표시되는지 확인합니다.
실제 분석은 대부분 RStudio에서 진행하므로, 최소한 RStudio는 작업표시줄에 고정해 두는 것을 권장합니다.

3) 자주 사용하는 폴더에 바로가기 복사하기

  1. 검색 결과의 R x.x.x를 오른쪽 클릭합니다.
  2. 파일 위치 열기를 선택합니다. 메뉴가 보이지 않으면 더 보기 → 파일 위치 열기를 선택합니다.
  3. 파일 탐색기에 표시된 R x.x.x 바로가기를 오른쪽 클릭하고 복사를 선택합니다.
  4. 바탕 화면이나 원하는 폴더로 이동한 뒤 붙여넣기합니다.
  5. RStudio도 시작 메뉴에서 검색한 뒤 같은 방법으로 바로가기를 복사합니다.
실제 프로그램 파일을 옮기지 마세요. 설치 폴더 안의 R.exe, Rgui.exe, rstudio.exe를 잘라내어 다른 폴더로 이동하면 프로그램 실행, 패키지 탐색 또는 업데이트가 정상적으로 작동하지 않을 수 있습니다. 이동하거나 복사할 대상은 파일 유형이 바로 가기인 항목입니다.

7R 버전과 패키지 호환성 이해하기

R은 주기적으로 새로운 버전이 발표됩니다. R 패키지는 모든 R 버전에서 똑같이 작동하는 독립 프로그램이 아니라, 특정 R 버전과 운영체제 환경에서 설치되고 실행됩니다.

구성 요소버전과 관련된 특징
R통계 계산을 실제로 실행하는 기본 환경이며, 예를 들어 R 4.5와 R 4.6은 서로 다른 설치로 관리됩니다.
CRAN package패키지마다 요구하는 최소 R 버전과 다른 패키지 의존성이 다를 수 있습니다.
Bioconductor각 Bioconductor release는 특정 R 버전에 맞춰 제공됩니다. 따라서 R과 Bioconductor 버전 조합이 맞아야 합니다.
RStudio설치된 R 중 하나를 선택하여 실행합니다. RStudio 자체 버전과 현재 R session의 버전은 서로 다른 개념입니다.

R을 업데이트한 뒤 패키지가 없어 보이는 이유

Windows에서는 R의 주요 버전별로 package library가 나뉘는 경우가 많습니다. 예를 들어 이전 R에서 설치한 패키지가 새 R의 library에 자동으로 설치되는 것은 아닙니다. 따라서 R을 업데이트한 직후 다음과 같은 오류가 나타날 수 있습니다.

Error in library(GEOquery) :
  there is no package called 'GEOquery'

이 메시지는 GEOquery가 세상에서 사라졌다는 뜻이 아니라, 현재 실행 중인 R이 사용하는 library에 GEOquery가 설치되어 있지 않다는 의미일 수 있습니다.

Bioconductor가 R 버전에 의존하는 이유

Bioconductor는 독자적인 release 주기를 가지며 각 release가 특정 R 버전에 맞춰 설계됩니다. R만 먼저 최신 버전으로 바꾸거나 서로 다른 Bioconductor release의 패키지를 섞으면 다음 문제가 발생할 수 있습니다.

  • package is not available for this version of R 메시지가 나타남
  • 필요한 dependency package가 설치되지 않음
  • 현재 R과 맞는 Windows binary가 아직 제공되지 않아 source 설치를 시도함
  • 새 R에서 기존 package가 보이지 않거나 다시 설치해야 함
  • 서로 다른 Bioconductor release의 package가 섞여 충돌함
중요: 무조건 가장 새로운 R이 항상 현재 분석에 가장 안정적인 것은 아닙니다. 새로운 수업이나 프로젝트를 시작할 때는 필요한 package가 해당 R 버전을 지원하는지 확인하고, 분석 도중에는 특별한 이유 없이 R을 업데이트하지 않는 것이 안전합니다.

현재 버전 확인

RStudio Console에서 다음 코드를 한 줄씩 실행합니다.

# 현재 R 버전
R.version.string

# R이 package를 찾는 폴더
.libPaths()

# Bioconductor 관리 package 설치
if (!require("BiocManager", quietly = TRUE))
  install.packages("BiocManager")

# 현재 R에 맞는 Bioconductor 버전
BiocManager::version()

# 너무 오래되었거나 너무 새로운 package 확인
BiocManager::valid()
Bioconductor package는 일반적으로 install.packages()가 아니라 BiocManager::install()로 설치합니다. BiocManager가 현재 R에 맞는 Bioconductor repository를 선택하도록 돕기 때문입니다.
Bioconductor 공식 설치 안내 R–Bioconductor 버전 대응표

R이 여러 버전 설치된 경우

오래된 프로젝트 때문에 이전 R을 남겨두면 Windows 검색 결과에 R 4.4, R 4.5, R 4.6처럼 여러 항목이 표시될 수 있습니다. 이것은 오류가 아닙니다.

  1. RStudio에서 Tools → Global Options → General을 엽니다.
  2. R version 또는 R Sessions 항목의 Change를 선택합니다.
  3. 이번 실습에서 사용할 R 버전을 선택합니다.
  4. 또는 Windows에서 Ctrl 키를 누른 상태로 RStudio를 실행하여 R 버전 선택 창을 열 수 있습니다.
  5. RStudio를 다시 시작한 뒤 R.version.string으로 실제 버전을 확인합니다.
바로가기 이름이나 설치 파일 이름만 보고 현재 RStudio가 사용하는 R 버전을 판단하지 않습니다. 반드시 RStudio Console에서 R.version.string을 실행해 확인합니다.

11자주 발생하는 문제

R이 먼저 설치되어 있는지 확인합니다. 설치 후 컴퓨터를 다시 시작하고 RStudio를 실행합니다.

RStudio 실행 시 Ctrl 키를 누른 채 시작하면 사용할 R 버전을 선택할 수 있습니다. 특별한 이유가 없다면 최신 버전을 사용합니다.

getwd()로 현재 작업 폴더를 확인합니다. 한글, 공백, OneDrive 동기화 경로를 피하고 RStudio Project를 사용합니다.

이번 입문 실습에서는 우선 설치하지 않아도 됩니다. Windows용 바이너리 패키지 설치만으로 대부분의 실습이 가능합니다. 소스 패키지 컴파일이 필요할 때 별도로 안내합니다.

먼저 R.version.string과 .libPaths()를 실행해 현재 R 버전과 package library를 확인합니다. 새 R은 이전 R과 다른 library를 사용할 수 있으므로 필요한 패키지를 현재 R에 다시 설치해야 할 수 있습니다.

install.packages("BiocManager")
BiocManager::install(c("GEOquery", "limma"))
BiocManager::valid()

오류 메시지에서 요구하는 R 버전을 먼저 확인합니다. BiocManager::version()과 BiocManager::valid()로 현재 조합을 점검하고, 패키지 공식 페이지의 설치 명령을 사용합니다. 수업 중에는 임의로 Bioconductor devel 버전이나 서로 다른 release의 저장소를 섞지 않습니다.
