GEO Microarray Analysis 과정 목차
Step 09

Cytoscape를 이용한 네트워크·모듈·Hub 분석

Cytoscape와 stringApp, MCODE, cytoHubba를 설치하고 DEG 네트워크에서 기능 모듈과 hub gene 후보를 탐색합니다.

이번 단계의 목표

Cytoscape 설치→ STRING network→ DEG 정보 결합→ MCODE→ cytoHubba

Cytoscape는 복잡한 네트워크를 시각화하고 node·edge에 다양한 데이터를 결합할 수 있는 오픈소스 소프트웨어입니다. 이번 실습에서는 Step 08의 STRING 분석을 데스크톱 환경으로 확장합니다.

탐색적 분석: MCODE module과 cytoHubba hub는 네트워크 위상에 기반한 후보입니다. 질병의 원인 유전자나 치료 표적을 자동으로 증명하는 결과는 아닙니다.

1. Windows에서 Cytoscape 설치

  1. 아래 공식 다운로드 페이지에 접속합니다.
  2. 사용권 내용을 확인하고 Windows 64-bit 설치 파일을 내려받습니다.
  3. 다운로드한 installer를 실행하고 안내에 따라 설치합니다.
  4. 설치가 끝나면 시작 메뉴에서 Cytoscape를 실행합니다.
  5. 처음 실행할 때 방화벽 메시지가 나타나면 기관 보안정책을 확인한 뒤 필요한 네트워크 접근을 허용합니다.
현재 Windows와 macOS용 플랫폼별 설치 패키지에는 필요한 OpenJDK Java 런타임이 함께 설치됩니다. 따라서 별도의 Java를 먼저 설치하기보다 공식 installer를 사용하는 것이 간단합니다.
Cytoscape 다운로드 운영체제별 설치 파일
실행되지 않을 때: 구형 Cytoscape 또는 Java 경로 충돌, 기관 PC의 설치 권한, 백신 프로그램 차단 여부를 확인합니다. 수업 전 모든 PC에서 Cytoscape가 실제로 실행되는지 점검하는 것이 좋습니다.

5. stringApp으로 DEG network 생성

설치된 stringApp으로 STRING network를 Cytoscape에 직접 불러옵니다.

권장 진입: File → Import → Network from Public Databases → Data Source에서 STRING protein query
  1. Data Source에서 STRING: protein query를 선택합니다.
  2. Up 또는 Down gene symbol을 입력창에 붙여넣습니다.
  3. Species를 Homo sapiens로 선택합니다.
  4. Confidence score를 설정합니다. 첫 실습은 0.4, 보다 엄격한 네트워크는 0.7을 사용할 수 있습니다.
  5. Maximum additional interactors를 0으로 설정합니다.
  6. Import를 눌러 network를 생성합니다.
추가 interactor를 0으로 설정하는 이유: 입력 DEG가 아닌 주변 단백질이 추가되면 MCODE와 cytoHubba 결과가 추가 단백질에 의해 달라질 수 있습니다.
Up과 Down network를 별도로 만들고 이름을 STRING_Up, STRING_Down처럼 변경해 두면 이후 분석에서 혼동을 줄일 수 있습니다.

6. Node Table에 Up·Down 정보 결합

STRING network가 만들어지면 각 node에는 STRING protein ID, gene symbol과 annotation이 저장됩니다. 이 Node Table을 먼저 내보낸 뒤 degs 열을 추가하고 다시 가져오면 Up·Down 정보를 정확하게 network에 연결할 수 있습니다.

6-1. 현재 Node Table 내보내기

  1. 화면 아래의 Node Table을 선택합니다.
  2. Table 위쪽의 Export Table 아이콘을 누릅니다.
  3. 파일 이름과 저장 위치를 지정하고 CSV 형식으로 저장합니다.

6-2. Excel에서 degs 열 추가

내보낸 CSV를 Excel에서 열고 새로운 열 이름을 degs로 지정합니다. 각 gene이 상향조절 유전자이면 up, 하향조절 유전자이면 down을 입력합니다.

  1. display name 또는 query term 열에서 gene symbol을 확인합니다.
  2. Step 05에서 저장한 Up·Down DEG 목록과 비교해 degs 열을 작성합니다.
  3. 기존 @id 열의 값과 행 순서는 변경하지 않습니다.
  4. CSV 형식으로 다시 저장합니다.
@id를 변경하지 마세요. @id는 Cytoscape network의 각 node를 구분하는 고유한 key입니다. 이 값이 삭제되거나 바뀌면 수정한 표를 기존 node에 정확히 연결할 수 없습니다.

6-3. 수정한 표를 Node Table로 가져오기

  1. Node Table 위쪽의 Import Table 아이콘을 누릅니다.
  2. 수정하여 저장한 CSV 파일을 선택합니다.
  3. Import Data as를 Node Table Columns로 지정합니다.
  4. Key Column for Network를 @id로 지정합니다.
  5. 가져올 표의 key도 @id인지 확인한 뒤 OK를 누릅니다.
Key Column for Network를 맞추는 것이 핵심입니다. 가져온 degs 값이 모두 비어 있거나 일부 node에 잘못 연결된다면 분석을 계속하지 말고 network와 입력 파일의 key 열 및 실제 값이 동일한지 먼저 확인하세요. 영문 대·소문자를 구분하도록 설정한 경우 값의 대·소문자도 같아야 합니다.

7. Up·Down 유전자의 색상 변경

Node Table에 추가한 degs 열을 Style의 Fill Color에 연결하면 상향조절 유전자와 하향조절 유전자를 서로 다른 색으로 표시할 수 있습니다.

  1. 왼쪽의 Style panel을 엽니다.
  2. Node 속성의 Fill Color를 펼칩니다.
  3. Column을 degs로 선택합니다.
  4. Mapping Type을 Discrete Mapping으로 설정합니다.
  5. up은 빨간색, down은 파란색처럼 원하는 색을 지정합니다.
  6. Label의 Column을 display name으로 지정해 gene symbol을 표시합니다.
색상에는 정해진 규칙이 없지만 일반적으로 Up은 빨간색, Down은 파란색을 많이 사용합니다. 그림 설명에 각 색상이 의미하는 발현 방향을 반드시 기록합니다.
이번 방식은 up/down이라는 범주를 색으로 구분하므로 Discrete Mapping을 사용합니다. logFC의 연속적인 크기를 색 농도로 표현하려는 경우에만 Continuous Mapping을 사용합니다.

8. MCODE로 밀집 모듈 탐색

MCODE는 서로 밀집하게 연결된 network 영역을 찾습니다. PPI network에서는 단백질 complex 또는 특정 기능을 공유하는 module 후보로 해석할 수 있습니다.

클릭 순서: Apps → MCODE → Open MCODE → Analyze Current Network
설정의미시작값 예시
Degree Cutoff이웃 연결 수가 너무 적은 node를 제외하는 기준2
Node Score CutoffCluster 확장 시 포함할 node score 기준0.2
K-Core각 node가 최소 k개 이상의 연결을 갖는 core 기준2
Max DepthSeed에서 cluster를 탐색하는 최대 깊이100

분석 후 cluster 목록에서 Score, node 수와 edge 수를 확인하고 상위 cluster를 선택해 별도 subnetwork로 생성합니다.

위 값은 보편적인 정답이나 최적값이 아니라 실습 시작값입니다. Network 크기와 밀도에 따라 결과가 달라지므로 사용한 parameter를 반드시 기록합니다.
각 MCODE module의 gene 목록을 내보내 DAVID 또는 STRING functional enrichment에 다시 입력하면 module별 생물학적 기능을 확인할 수 있습니다.

9. cytoHubba로 Hub 후보 탐색

cytoHubba는 network topology에 기반한 여러 알고리즘으로 node의 중요도를 계산합니다.

클릭 순서: 분석할 network 선택 → Apps → cytoHubba → 분석 시작
알고리즘의미주의점
Degree직접 연결된 이웃 수가 많은 node를 우선 선택단순하고 직관적이지만 연결 수에만 의존
MCCNode가 참여하는 maximal clique 구조를 이용밀집된 핵심 영역 탐색에 자주 사용
MNCNode 이웃으로 만들어지는 최대 연결 성분의 크기를 이용주변 연결 구조에 민감
Betweenness다른 node 사이의 최단경로에 얼마나 자주 위치하는지 평가서로 다른 module을 연결하는 node 탐색에 유용
Closeness다른 node까지의 평균 거리가 짧은 정도를 평가Network 연결성과 구조에 영향을 받음
  1. 처음 실습에서는 직관적인 Degree를 선택해 Top 10 node를 확인합니다.
  2. 같은 network에서 MCC Top 10도 확인합니다.
  3. 두 결과에 공통으로 포함된 gene을 확인합니다.
  4. 필요하면 Betweenness 결과를 추가해 module 연결 후보를 확인합니다.
  5. 순위 결과를 table로 저장합니다.

STRING ID 대신 gene symbol 표시하기

cytoHubba 결과의 node label이 9606.ENSP... 형태로 보일 수 있습니다. 이 값은 STRING protein identifier이며 분석 오류가 아닙니다. 다음 순서로 표시 열을 바꿉니다.

클릭 순서: Style → Node → Label → Column → display name
  1. 왼쪽 Style panel을 열고 Node 속성을 선택합니다.
  2. Label 항목을 펼칩니다.
  3. Column을 display name으로 선택합니다.
  4. Mapping Type은 Passthrough Mapping으로 설정합니다.
  5. 네트워크 node가 CCL2, IL6 같은 gene symbol로 표시되는지 확인합니다.
display name 열이 보이지 않으면 아래 Node Table에서 gene symbol이 실제로 들어 있는 열을 먼저 확인하세요. Cytoscape와 stringApp 버전에 따라 display name, query term, name 등 열 이름이 달라질 수 있습니다.
Hub gene ≠ 원인 유전자: Hub 순위는 STRING의 자료 편향, network score, 추가 interactor와 선택 알고리즘에 영향을 받습니다. DEG의 logFC·FDR, MCODE module, pathway 및 외부 검증을 함께 확인해야 합니다.

12. 자주 발생하는 문제

문제확인 방법
App 설치 후 메뉴가 보이지 않음App Manager의 Installed 목록을 확인하고 Cytoscape를 다시 실행합니다.
STRING 검색 결과가 없음Gene symbol, species와 인터넷 연결을 확인합니다.
DEG table 값이 모두 비어 있음CSV와 Node Table에서 gene symbol이 들어 있는 key column을 다시 확인합니다.

그림의 label이 겹침Layout을 변경하고 label 크기, node 간격과 표시할 node 수를 조정합니다.
