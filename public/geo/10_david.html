Step 10

DAVID를 이용한 GO·KEGG 분석

Step 09에서 준비한 Up·Down·background 목록으로 과대표현분석을 수행합니다.

DAVID에서 수행할 분석

DAVID는 입력 유전자 목록에 특정 기능 annotation이 background에 비해 과대표현되어 있는지 평가하는 웹 기반 기능 주석 도구입니다.

Up genes→ GO·KEGG ORA Down genes→ GO·KEGG ORA
DAVID 공식 홈페이지

1. 입력 파일 확인

input_dir <- "results/enrichment_input"

up_genes <- readLines(
  file.path(input_dir, "up_gene_symbols.txt")
)
down_genes <- readLines(
  file.path(input_dir, "down_gene_symbols.txt")
)
background_genes <- readLines(
  file.path(input_dir, "background_gene_symbols.txt")
)

length(up_genes)
length(down_genes)
length(background_genes)

Gene symbol 대신 Entrez ID를 사용할 경우 각각 up_entrez_ids.txt, down_entrez_ids.txt, background_entrez_ids.txt를 사용합니다.

목록이 비어 있다면 DAVID 분석을 강제로 진행하지 않습니다. Step 08의 DEG 기준과 Step 09의 conflict·mapping report를 확인하고, 유의 DEG가 없다면 GSEA를 고려합니다.

2. Gene list 업로드

  1. DAVID의 Functional Annotation 도구를 엽니다.
  2. up_gene_symbols.txt의 내용을 한 줄에 하나씩 붙여넣거나 파일을 업로드합니다.
  3. Identifier를 OFFICIAL_GENE_SYMBOL로 지정합니다.
  4. List Type을 Gene List로 선택합니다.
  5. Species가 Homo sapiens인지 확인합니다.
Entrez 파일을 사용한다면 Identifier도 ENTREZ_GENE_ID로 변경해야 합니다. 파일의 ID 종류와 DAVID의 Identifier 선택이 다르면 mapping rate가 낮아집니다.

3. 사용자 background 등록

background_gene_symbols.txt 또는 background_entrez_ids.txt를 background 목록으로 등록합니다. Gene List와 background는 같은 ID 체계를 사용해야 합니다.

Gene ListBackgroundIdentifier
up_gene_symbols.txtbackground_gene_symbols.txtOFFICIAL_GENE_SYMBOL
up_entrez_ids.txtbackground_entrez_ids.txtENTREZ_GENE_ID
Up은 Up background, Down은 Down background를 사용하는 것이 아닙니다. 두 분석 모두 실제 DEG가 선택될 수 있었던 동일한 전체 분석 유전자 background를 사용합니다.

4. GO와 KEGG 결과 확인

Functional Annotation 결과에서 다음 범주를 확인합니다.

  • Gene Ontology Biological Process
  • Gene Ontology Cellular Component
  • Gene Ontology Molecular Function
  • KEGG Pathway

5. Up과 Down을 각각 반복 분석

  1. Up 목록과 전체 background로 분석하고 결과를 내려받습니다.
  2. 현재 Gene List를 Down 목록으로 교체합니다.
  3. 동일한 ID 체계와 동일한 background를 유지합니다.
  4. GO BP·CC·MF와 KEGG 결과를 각각 내려받습니다.
  5. Up과 Down 결과에서 공유되거나 반대 방향으로 나타나는 기능을 비교합니다.

6. 결과 해석 시 주의사항

  • P-value만 보지 않고 Benjamini 등 다중검정 보정값을 우선 확인합니다.
  • Count가 매우 작은 term은 일부 유전자에 의해 결과가 좌우될 수 있습니다.
  • GO term은 계층구조와 유전자 공유 때문에 서로 중복됩니다.
  • Fold Enrichment가 크더라도 유전자 수와 FDR이 불충분할 수 있습니다.
  • 같은 유전자가 여러 term과 pathway를 동시에 유의하게 만들 수 있습니다.
  • Pathway 이름만 보고 활성·억제를 결정하지 않고 포함 유전자를 확인합니다.
  • DAVID의 데이터베이스 버전과 분석 날짜를 기록합니다.

실습 문제

  1. Up과 Down 분석에 사용한 gene 수, background 수와 mapping rate를 기록합니다.
  2. Up GO BP와 Down GO BP에서 FDR이 가장 작은 term 5개를 정리합니다.
  3. Up과 Down에 공통으로 나타나는 term이 있다면 구성 유전자를 비교합니다.
  4. KEGG 결과에서 Count, Fold Enrichment와 FDR을 함께 고려해 후보 pathway를 선택합니다.
  5. 선택한 pathway가 활성화 또는 억제되었다고 단정할 수 있는지 근거를 작성합니다.
