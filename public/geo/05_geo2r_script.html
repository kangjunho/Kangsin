Step 05

GEO 데이터 직접 전처리와 DEG 분석

GSE69657의 발현값·임상정보·probe annotation을 직접 분리하고, GEO2R와 다른 전처리 흐름으로 차등발현 분석을 수행합니다.

이번 단계의 분석 흐름

GEO 다운로드→ exprs·pData·fData→ 전처리→ Probe→Gene→ limma
  1. 30개 sample의 Series Matrix를 내려받고 ExpressionSet 구조를 이해합니다.
  2. chemoresponse:ch1 정보를 이용해 responder와 nonresponder를 구분합니다.
  3. Series Matrix에는 log2 변환과 quantile normalization을 적용합니다.
  4. 여러 probe가 같은 gene symbol을 가리키면 aggregate()로 평균을 계산합니다.
  5. 추가 실습에서는 제공되는 raw CEL 파일에 RMA를 적용합니다.

3. exprs(), pData(), fData() 이해하기

getGEO()가 반환한 ExpressionSet에는 서로 연결된 세 개의 데이터 표가 들어 있습니다. 정확히는 exprs()는 숫자형 matrix이고, pData()와 fData()는 data.frame입니다.

객체행열설명
exprs(gset) Probe ID GSM sample probe 이름으로 구성된 숫자형 발현값 행렬(matrix)입니다. 데이터프레임처럼 행과 열로 확인할 수 있습니다.
pData(gset) GSM sample 임상·실험 변수 성별, 나이, 병기, 치료반응과 같은 sample 임상정보가 포함된 데이터프레임입니다.
fData(gset) Probe ID 유전자 annotation Probe ID와 gene symbol, gene title 등의 대응정보가 포함된 데이터프레임입니다. 
expression_data <- exprs(gset)
sample_metadata <- pData(gset)
probe_annotation <- fData(gset)

발현값 데이터: exprs()

행은 Affymetrix probe ID이고 열은 GSM sample입니다. 한 숫자는 특정 sample에서 특정 probe가 측정한 발현 강도입니다.

임상정보: pData()

각 행은 GSM sample이며 성별, 나이, 병기, 조직과 chemoresponse 정보가 포함되어 있습니다.

Probe annotation: fData()

각 probe ID가 어떤 gene symbol과 gene title에 대응하는지를 보여줍니다. 하나의 gene에 여러 probe가 대응할 수 있습니다.

데이터가 올바르게 연결되어 있는지 확인

# expression의 열과 pData의 행은 같은 sample 순서여야 합니다.
identical(colnames(expression_data), rownames(sample_metadata))

# expression의 행과 fData의 행은 같은 probe 순서여야 합니다.
identical(rownames(expression_data), rownames(probe_annotation))
두 결과가 모두 TRUE인지 확인합니다. 임의로 정렬한 뒤 이름을 확인하지 않으면 발현값과 임상정보가 다른 환자에게 연결될 수 있습니다.

6. 30개 Series Matrix 전처리

Series Matrix는 이미 제출자가 처리하여 GEO에 올린 값이므로 raw CEL에 사용하는 RMA를 그대로 적용할 수 없습니다. 이번 주 실습에서는 GEO2R의 자동판단 대신 전처리 과정을 직접 확인합니다.

ex <- expression_data

quantile(
  ex,
  probs = c(0, 0.25, 0.5, 0.75, 0.99, 1),
  na.rm = TRUE
)

# 현재 값의 범위가 크므로 log2 변환
ex[ex <= 0] <- NA_real_
ex_log2 <- log2(ex)

# sample 간 분포를 동일하게 맞추는 quantile normalization
ex_normalized <- normalizeBetweenArrays(
  ex_log2,
  method = "quantile"
)

boxplot(
  ex_log2,
  outline = FALSE,
  las = 2,
  main = "Before quantile normalization"
)
boxplot(
  ex_normalized,
  outline = FALSE,
  las = 2,
  main = "After quantile normalization"
)
왜 GEO2R와 결과가 달라질 수 있나요? GEO2R은 데이터 상태를 자동판단하고 기본 설정에서는 추가 정규화를 강제하지 않을 수 있습니다. 여기서는 log2 변환과 quantile normalization을 명시적으로 적용하므로 분석 결과가 완전히 같지 않아도 오류라고 단정할 수 없습니다.

7. Probe ID를 gene symbol로 합치기

Affymetrix에서는 하나의 유전자를 여러 probe set이 측정할 수 있습니다. 전처리된 probe 발현값에 gene symbol을 붙이고, 같은 gene symbol에 속하는 probe들의 평균을 계산합니다.

순서가 중요합니다. RMA 또는 quantile normalization은 probe-level 자료에서 먼저 수행하고, aggregate()는 그 다음에 수행합니다. Gene symbol로 먼저 평균내면 RMA가 필요로 하는 probe-level 구조가 사라집니다. 
colnames(probe_annotation)

# GPL570 fData에서 gene symbol 열 사용
gene_symbol <- as.character(
  probe_annotation[rownames(ex_normalized), "Gene.symbol"]
)

# "DDR1 /// MIR4640"처럼 여러 symbol이 있으면 첫 symbol 사용
gene_symbol <- trimws(sub("///.*$", "", gene_symbol))

expression_with_symbol <- data.frame(
  Gene.symbol = gene_symbol,
  ex_normalized,
  check.names = FALSE
)

# symbol이 없거나 "---"인 probe 제외
keep_symbol <-
  !is.na(expression_with_symbol$Gene.symbol) &
  expression_with_symbol$Gene.symbol != "" &
  expression_with_symbol$Gene.symbol != "---"

expression_with_symbol <-
  expression_with_symbol[keep_symbol, ]

# 같은 gene symbol의 여러 probe 값을 sample별 평균으로 통합
gene_expression_df <- aggregate(
  . ~ Gene.symbol,
  data = expression_with_symbol,
  FUN = mean,
  na.rm = TRUE
)

rownames(gene_expression_df) <- gene_expression_df$Gene.symbol
gene_expression <- as.matrix(
  gene_expression_df[, -1, drop = FALSE]
)

dim(ex_normalized)
dim(gene_expression)
head(gene_expression)

aggregate(..., FUN=mean)은 이해하기 쉬운 대표 방법이지만 유일한 정답은 아닙니다. 가장 변동이 큰 probe, 가장 높은 평균 발현 probe 또는 annotation 품질이 좋은 probe를 선택하는 방법도 있으므로 논문 Methods에 선택 기준을 기록합니다.

8. Gene-level limma 분석

design <- model.matrix(~ 0 + group)
colnames(design) <- c("Responder", "Nonresponder")
rownames(design) <- colnames(gene_expression)

contrast_matrix <- makeContrasts(
  Responder_vs_Nonresponder =
    Responder - Nonresponder,
  levels = design
)

fit <- lmFit(gene_expression, design)
fit2 <- contrasts.fit(fit, contrast_matrix)
fit2 <- eBayes(fit2)

deg_results <- topTable(
  fit2,
  coef = "Responder_vs_Nonresponder",
  adjust.method = "BH",
  sort.by = "P",
  number = Inf
)

deg_results$Gene.symbol <- rownames(deg_results)

up_degs <- deg_results[
  deg_results$P.Value < 0.05 &
  deg_results$logFC > 1,
]
down_degs <- deg_results[
  deg_results$P.Value < 0.05 &
  deg_results$logFC < -1,
]

write.csv(
  deg_results,
  "results/GSE69657_all_genes.csv",
  row.names = FALSE,
  fileEncoding = "CP949"
)
write.csv(
  up_degs,
  "results/GSE69657_up_degs.csv",
  row.names = FALSE,
  fileEncoding = "CP949"
)
write.csv(
  down_degs,
  "results/GSE69657_down_degs.csv",
  row.names = FALSE,
  fileEncoding = "CP949"
)
logFC 방향: 현재 contrast는 Responder − Nonresponder입니다. logFC가 양수이면 responder에서 높고, 음수이면 nonresponder에서 높습니다.

9. 선택 실습: raw CEL 파일과 RMA

RMA(Robust Multi-array Average)는 Affymetrix raw CEL 자료에 배경보정, quantile normalization과 probe-set summarization을 순서대로 적용하여 log2 발현값을 만드는 전처리 방법입니다.

RMA 과정의미
Background correction비특이적 신호와 기술적 배경을 보정합니다.
Quantile normalizationarray 사이의 전체 발현값 분포를 동일하게 맞춥니다.
Summarization여러 probe 신호를 하나의 probe-set 발현값으로 요약합니다.
log2 scaleRMA 결과는 log2 scale로 반환됩니다.
