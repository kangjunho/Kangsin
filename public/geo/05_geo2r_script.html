GEO Microarray Analysis 과정 목차
Step 05

발현데이터 직접 분석과 GEO2R 비교

exprs(), pData(), fData()를 직접 다루고, 같은 비교를 limma로 수행하여 GEO2R 결과와 검산합니다.

이번 단계의 목표

  1. GSE69657의 ExpressionSet에서 발현값, sample metadata와 probe annotation을 각각 추출합니다.
  2. pData()의 실제 임상정보를 읽어 Responder와 Non_responder 그룹을 만듭니다.
  3. 직접 만든 design과 contrast로 probe 수준의 limma 분석을 수행합니다.
  4. 내 결과와 GEO2R 전체 결과를 probe ID로 연결하여 logFC와 P-value를 비교합니다.
Step 04와의 차이: Step 04는 GEO2R 웹 화면에서 그룹과 결과를 이해하는 단계였습니다. 이번 단계는 GEO2R가 하던 작업을 데이터 구조부터 직접 확인하고 재현하는 단계입니다.

3. ExpressionSet의 세 가지 표

ExpressionSet은 발현값만 담는 표가 아닙니다. 분석에 필요한 세 종류의 정보를 서로 맞는 순서로 보관합니다.

함수행열의미
exprs(gset)probeGSM sample정규화된 microarray 발현값
pData(gset)GSM sample임상·실험 변수질환, 반응, 조직, 성별 등의 sample metadata
fData(gset)probe유전자 정보probe ID, gene symbol, gene title 등의 annotation
 
expression_data <- exprs(gset)
sample_metadata <- pData(gset)
probe_annotation <- fData(gset)

dim(expression_data)
dim(sample_metadata)
dim(probe_annotation)

# 반드시 TRUE여야 하는 두 가지 정렬 조건
identical(colnames(expression_data), rownames(sample_metadata))
identical(rownames(expression_data), rownames(probe_annotation))
초보자가 가장 많이 헷갈리는 부분: 발현행렬에서는 sample이 열이지만, sample metadata에서는 sample이 행입니다. 두 객체를 임의로 정렬하면 sample과 그룹이 어긋날 수 있으므로 이름으로 일치 여부를 확인합니다.

Responder와 Non_responder 만들기

response_text <- tolower(
  trimws(as.character(sample_metadata[[response_col]]))
)

# non-responder를 먼저 검사해야 responder라는 부분문자열과 혼동하지 않습니다.
group_text <- ifelse(
  grepl("non[-_ ]?responder", response_text),
  "Non_responder",
  ifelse(grepl("responder", response_text), "Responder", NA)
)

group <- factor(
  group_text,
  levels = c("Responder", "Non_responder")
)

table(group, useNA = "ifany")

group_check <- data.frame(
  GSM = rownames(sample_metadata),
  original_value = sample_metadata[[response_col]],
  group = group
)
View(group_check)

응답 정보가 R과 NR처럼 기록되어 있다면 위의 패턴 대신 실제 값으로 변환합니다.

# 예시: 실제 값이 R과 NR일 때만 사용
group_text <- ifelse(
  response_text == "r", "Responder",
  ifelse(response_text == "nr", "Non_responder", NA)
)
분석 전 중단 조건: table(group, useNA="ifany")에 NA가 있거나, GEO2R에서 확인한 그룹별 sample 수와 다르면 다음 단계로 넘어가지 않습니다.

5. 발현값 확인과 log2 변환

ex <- expression_data
qx <- quantile(
  ex,
  probs = c(0, 0.25, 0.5, 0.75, 0.99, 1),
  na.rm = TRUE
)
qx

log_needed <- (qx[5] > 100) ||
  ((qx[6] - qx[1] > 50) && qx[2] > 0)

if (log_needed) {
  ex[ex <= 0] <- NA_real_
  ex <- log2(ex)
}

keep <- rowSums(is.na(ex)) == 0
ex <- ex[keep, , drop = FALSE]
probe_annotation <- probe_annotation[rownames(ex), , drop = FALSE]

이 판단식은 GEO2R의 자동 판단 방식을 재현한 것입니다. 최종 분석에서는 GSE의 Data processing 설명과 발현값 분포를 함께 확인해야 합니다.

6. limma로 직접 분석하기

이번 비교 방향은 Responder − Non_responder입니다. 따라서 logFC가 양수이면 Responder에서 더 높고, 음수이면 Non_responder에서 더 높습니다.

design <- model.matrix(~ 0 + group)
colnames(design) <- levels(group)
rownames(design) <- colnames(ex)

design
colSums(design)

contrast_matrix <- makeContrasts(
  Responder_vs_Non_responder =
    Responder - Non_responder,
  levels = design
)
contrast_matrix

fit <- lmFit(ex, design)
fit2 <- contrasts.fit(fit, contrast_matrix)
fit2 <- eBayes(fit2, proportion = 0.01)

local_results <- topTable(
  fit2,
  coef = "Responder_vs_Non_responder",
  adjust.method = "BH",
  sort.by = "B",
  number = Inf
)
local_results$ID <- rownames(local_results)
방향 확인: GEO2R에서 설정한 첫 번째 그룹과 두 번째 그룹의 순서가 다르면 logFC 부호가 반대로 나옵니다. 비교 전에 GEO2R contrast와 R의 contrast_matrix가 같은 방향인지 확인하세요.

10. 결과가 다를 때 확인할 항목

확인 항목차이가 생기는 이유
sample과 그룹제외한 sample, 그룹 이름 또는 contrast 방향이 다르면 결과가 달라집니다. 방향만 반대라면 logFC 부호가 거의 정확히 반전됩니다.
log2 변환한쪽만 log2 변환했거나 이미 변환된 값을 다시 변환하면 효과크기가 달라집니다.
OptionsGEO2R의 force normalization, P-value adjustment와 annotation 선택이 로컬 설정과 다를 수 있습니다.
패키지 버전GEO2R 서버와 내 R의 GEOquery, limma 및 annotation 버전 차이로 작은 수치 차이가 생길 수 있습니다.
결측 probe 처리NA를 제거한 시점이나 방법이 다르면 검정 대상 probe 수와 FDR이 달라집니다.
annotationGene symbol이 달라도 probe 수준 통계량은 같을 수 있습니다. 우선 gene symbol이 아니라 ID로 병합합니다.
비교의 순서: 먼저 병합된 probe 수를 확인하고, 다음으로 logFC 방향과 크기, 그 다음 P-value와 adjusted P-value를 확인합니다. annotation 열부터 비교하면 분석 결과와 주석 버전의 차이를 혼동하기 쉽습니다.

따라하기 실습

  1. exprs(), pData(), fData()의 행·열 수를 기록하고 무엇을 뜻하는지 설명합니다.
  2. 두 identical() 결과가 모두 TRUE인지 확인합니다.
  3. pData()에서 반응 정보가 들어 있는 열과 가능한 값을 찾아 기록합니다.
  4. GSM, 원래 반응 정보, 새 그룹을 포함한 group_check 표를 만들고 그룹별 sample 수를 확인합니다.
  5. Responder - Non_responder 방향으로 전체 probe의 limma 결과를 저장합니다.
  6. GEO2R 전체 결과를 내려받아 probe ID로 병합합니다.
  7. 병합된 probe 수, logFC 상관계수, 최대 절댓값 차이와 방향 일치율을 기록합니다.
  8. 결과가 완전히 같지 않다면 위 표에서 가능한 원인을 두 가지 이상 찾아 설명합니다.
