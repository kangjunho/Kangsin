1R Script와 코드 실행

RStudio를 처음 실행하면 아래처럼 왼쪽에는 Console만 보이고, 코드를 작성하는 Source 영역은 보이지 않을 수 있습니다. 이것은 오류가 아니라 아직 R Script를 만들지 않은 상태입니다.

새 R Script 만들기

  1. RStudio 상단에서 File → New File → R Script를 선택합니다.
  2. 또는 키보드에서 Ctrl + Shift + N을 누릅니다.
  3. 왼쪽 위에 Untitled1이라는 Source 창이 나타나는지 확인합니다.
Source와 Console의 차이: Source는 앞으로 다시 사용할 코드를 작성하고 저장하는 공간이고, Console은 코드의 실행 결과와 오류 메시지가 나타나는 공간입니다.

첫 번째 코드 작성과 실행

Source 창에 다음 코드를 그대로 입력합니다.

# # 뒤의 문장은 설명을 위한 주석이며 실행되지 않습니다.
1 + 1

print("Hello, GEO analysis!")
  1. 실행할 코드 한 줄에 마우스 커서를 둡니다.
  2. Ctrl + Enter를 누르거나 Source 오른쪽 위의 Run을 클릭합니다.
  3. 여러 줄을 한 번에 실행하려면 마우스로 코드를 선택한 뒤 Ctrl + Enter를 누릅니다.
  4. 실행된 코드와 결과가 왼쪽 아래 Console에 나타나는지 확인합니다.

Script 저장하기

  1. Ctrl + S를 누르거나 File → Save를 선택합니다.
  2. 실습 폴더 안의 scripts 폴더를 선택합니다.
  3. 파일 이름을 01_r_basics.R로 저장합니다.
Console에 직접 입력한 내용은 분석 과정이 Script에 남지 않습니다. 연구 분석에 사용한 코드는 가능한 한 Source에 작성하고 .R 파일로 저장합니다.
자주 사용하는 단축키: 새 Script는 Ctrl + Shift + N, 저장은 Ctrl + S, 현재 줄 또는 선택 영역 실행은 Ctrl + Enter입니다.

2작업 폴더 이해하기

작업 폴더(working directory)는 R이 파일을 읽고 저장할 때 기준으로 사용하는 폴더입니다. 파일명만 입력했을 때 R은 이 폴더를 기준으로 파일을 찾습니다.

현재 작업 폴더 확인

getwd()

getwd()는 get working directory의 줄임말입니다. 실행 결과로 현재 R이 기준으로 사용하는 폴더의 전체 경로가 출력됩니다.

Windows에서 작업 폴더 경로 확인

  1. 파일 탐색기에서 작업에 사용할 폴더를 찾습니다.
  2. 해당 폴더를 마우스 오른쪽 버튼으로 클릭하고 속성을 선택합니다.
  3. 일반 탭에서 위치에 표시된 상위 경로를 확인합니다.
  4. 위치 뒤에 현재 폴더 이름을 붙여 전체 경로를 만듭니다.
‘위치’만 복사하면 상위 폴더까지만 지정될 수 있습니다. 실제로 사용할 폴더 이름까지 포함되었는지 확인합니다. 사용자 이름의 USER 또는 admin 부분은 컴퓨터마다 다르므로 예시 경로를 그대로 복사하지 않습니다.

작업 폴더 변경

setwd()는 set working directory의 줄임말입니다. Windows에서는 다음 두 표현을 모두 사용할 수 있습니다. 

# 방법 1: 슬래시(/) 사용 — 가장 간단하고 권장
setwd("C:/Users/admin/OneDrive/Desktop/Bioinformatics/GEO_microarray/")

# 방법 2: 역슬래시를 두 번(\\) 사용
setwd("C:\\Users\\admin\\OneDrive\\Desktop\\Bioinformatics\\GEO_microarray/")

# 변경된 작업 폴더 확인
getwd()

왜 \를 두 번 써야 할까요?

Windows 탐색기에서는 폴더를 C:\Users\admin처럼 표시합니다. 하지만 R 문자열에서 단일 역슬래시(\)는 줄바꿈(\n), 탭(\t)과 같은 특수문자를 시작하는 escape 문자입니다.

따라서 R 경로에서는 /를 사용하거나, 실제 역슬래시 하나를 표현하기 위해 \\를 사용합니다. 즉 /와 \\가 문자로 같은 것은 아니지만, Windows의 R 파일 경로에서는 두 방식이 같은 위치를 가리킬 수 있습니다.

잘못된 예

# 단일 역슬래시는 오류 또는 의도하지 않은 escape 처리를 유발
setwd("C:\Users\admin\OneDrive\Desktop\Bioinformatics\GEO_microarray")
OneDrive 경로 주의: 일반적인 실습 파일에는 사용할 수 있지만, 동기화 중 파일 잠금이나 긴 경로 문제가 생길 수 있습니다. 대용량 GEO 파일이나 반복 분석은 C:/Bioinformatics/GEO_microarray/처럼 OneDrive 밖의 짧은 영문 경로가 더 안정적입니다. 마지막의 /는 있어도 되고 없어도 됩니다.

폴더와 파일 확인

# 현재 폴더의 파일과 하위 폴더 확인
list.files()

# 폴더가 없다면 생성
dir.create("data_raw", showWarnings = FALSE)
dir.create("results", showWarnings = FALSE)

# 폴더를 만든 후 다시 확인
list.files()

# 특정 폴더가 존재하는지 TRUE/FALSE로 확인
dir.exists("data_raw")
dir.exists("results")

dir.create()를 사용하면 파일 탐색기에서 직접 만들지 않아도 R 코드로 하위 폴더를 생성할 수 있습니다. showWarnings = FALSE는 같은 폴더가 이미 있을 때 경고 메시지를 표시하지 않도록 하는 옵션입니다.

이 과정의 권장 방식: setwd()는 개념을 이해하기 위해 배우지만, 실제 분석에서는 Step 00에서 만든 RStudio Project를 열어 작업 폴더를 자동 설정합니다. 개인 컴퓨터의 절대경로를 Script에 반복해서 적으면 다른 컴퓨터에서 코드가 작동하지 않을 수 있습니다.

3객체와 자료형

R에서는 숫자, 문자, 표와 분석 결과를 객체(object)에 저장합니다. 할당 연산자 <-는 오른쪽 값을 왼쪽 이름에 저장한다는 뜻입니다. 

# 객체 만들기
sample_number <- 20
disease_name <- "Major depressive disorder"
is_case <- TRUE

# 객체 확인
sample_number
disease_name
is_case

# 자료형 확인
class(sample_number)
class(disease_name)
class(is_case)
자료형 의미 예시
numeric 숫자 20, 3.14
character 문자 "Control"
logical 논리값 TRUE, FALSE
factor 범주형 그룹 Control, Disease
객체 이름은 영문으로 시작하고 의미가 드러나게 작성합니다. 예: expr_matrix, sample_info, deg_result

4벡터와 인덱싱

벡터는 같은 종류의 여러 값을 하나로 묶는 R의 기본 자료구조입니다. c() 함수로 만듭니다. 

# 숫자와 문자 벡터
age <- c(34, 42, 51, 29, 47)
group <- c("Control", "Control", "Disease", "Disease", "Disease")

# 길이와 값 확인
length(age)
age

# 위치로 선택: R의 위치 번호는 1부터 시작
age[1]
age[2:4]

# 조건으로 선택
age[age >= 40]
group[group == "Disease"]
중요: 비교할 때 ==를 사용합니다. <-는 값을 저장하고, ==는 두 값이 같은지 비교합니다.

5데이터프레임

데이터프레임(data frame)은 행과 열로 구성된 표 형태의 객체입니다. 각 행은 하나의 관측치 또는 샘플이고, 각 열은 해당 샘플에서 측정한 변수입니다. GEO 분석에서는 sample metadata와 DEG 결과가 주로 데이터프레임으로 저장됩니다.

구성 의미 sample_info 예
행(row) 하나의 관측치 또는 샘플 GSM001 한 개
열(column) 샘플에서 측정한 변수 group, sex, age
셀(cell) 특정 샘플의 특정 변수 값 GSM001의 age = 41

예제 데이터프레임 만들기

sample_info <- data.frame(
  sample_id = paste0("GSM00", 1:8),
  group = c("Control", "Control", "Control", "Control",
            "Disease", "Disease", "Disease", "Disease"),
  sex = c("F", "M", "F", "M", "F", "M", "F", "M"),
  age = c(41, 38, 45, 52, 49, 55, 61, 44),
  marker_expression = c(5.2, 4.8, 5.5, 5.0, 7.1, 6.8, 7.5, 6.2)
)

sample_info

구조와 크기 확인

class(sample_info)       # 객체 종류
str(sample_info)         # 각 열의 자료형과 구조
dim(sample_info)         # 행 수와 열 수
nrow(sample_info)        # 행 수: 샘플 수
ncol(sample_info)        # 열 수: 변수 수
names(sample_info)       # 열 이름
head(sample_info, 3)     # 처음 3행

행과 열 선택

# 기본 형식: 데이터프레임[행, 열]
sample_info[1, ]                         # 첫 번째 행
sample_info[, "age"]                    # age 열
sample_info$age                          # $로 age 열 선택
sample_info[1:3, c("sample_id", "age")] # 1~3행의 두 열

조건에 맞는 행 추출

# Disease 샘플
sample_info[sample_info$group == "Disease", ]

# 50세 이상 샘플
sample_info[sample_info$age >= 50, ]

# Disease이면서 여성인 샘플: &는 AND
sample_info[
  sample_info$group == "Disease" & sample_info$sex == "F",
]

# Control이거나 60세 이상인 샘플: |는 OR
sample_info[
  sample_info$group == "Control" | sample_info$age >= 60,
]

새로운 열 추가와 요약 계산

# 연령 범주 추가
sample_info$age_group <- ifelse(
  sample_info$age >= 50,
  "50_or_older",
  "under_50"
)

# 그룹별 샘플 수
table(sample_info$group)

# Disease 그룹의 평균 연령
mean(sample_info$age[sample_info$group == "Disease"])

# 그룹별 marker 평균
aggregate(
  marker_expression ~ group,
  data = sample_info,
  FUN = mean
)
sample_info[행, 열] 순서입니다. 쉼표 앞은 행 조건, 뒤는 가져올 열을 의미합니다. 조건식은 각 행마다 TRUE 또는 FALSE를 만들고, R은 TRUE인 행만 남깁니다.

6자주 사용하는 기본 내장함수

함수는 입력값을 받아 정해진 작업을 수행합니다. 기본 구조는 함수이름(입력값, 옵션)입니다.

함수 용도 예시
c() 값을 벡터로 묶기 c(1, 2, 3)
length() 값의 개수 length(age)
dim() 행과 열 개수 dim(sample_info)
head() / tail() 처음/마지막 부분 확인 head(sample_info)
str() 객체의 내부 구조 str(sample_info)
class() 객체 종류 class(age)
summary() 기초 요약 통계 summary(age)
mean() / median() 평균/중앙값 mean(age)
min() / max() 최솟값/최댓값 max(age)
sum() 합계 또는 TRUE 개수 sum(age >= 40)
table() 범주별 빈도 table(group)
unique() 중복 없는 값 unique(group)
is.na() 결측값 확인 sum(is.na(age))
sort() 값 정렬 sort(age)
names() 열 또는 요소 이름 names(sample_info)

결측값이 있을 때

age_with_na <- c(34, 42, NA, 29, 47)

mean(age_with_na)                 # 결과: NA
mean(age_with_na, na.rm = TRUE)   # NA를 제외하고 계산

7R package란?

R package는 특정 분석을 위해 만들어진 함수, 설명서, 예제 데이터 등을 하나로 묶은 확장 도구입니다.

기본 R은 계산기와 기본 공구가 들어 있는 도구상자입니다.

R package는 GEO 다운로드, DEG 분석, 그래프 작성 등 특정 작업에 필요한 전문 공구를 추가하는 것입니다.

패키지 GEO 과정에서의 역할 저장소
GEOquery GEO 데이터와 임상정보 다운로드 Bioconductor
limma Microarray DEG 분석 Bioconductor
Biobase 발현 데이터 객체 관리 Bioconductor
AnnotationDbi Probe와 유전자 정보 연결 Bioconductor
ggplot2 분석 결과 시각화 CRAN
pheatmap 발현 heatmap 작성 CRAN

8CRAN과 Bioconductor

구분 CRAN Bioconductor
주요 목적 통계, 데이터 처리, 시각화 등 범용 R 패키지 유전체와 생물정보학 분석 패키지
설치 함수 install.packages() BiocManager::install()
예시 ggplot2, pheatmap, dplyr GEOquery, limma, Biobase

패키지가 어디에서 제공되는지 검색하기

패키지의 저장소를 모를 때는 Google에서 패키지 이름 + in r 형태로 검색할 수 있습니다. 다만 블로그나 복사된 설치 명령보다 CRAN 또는 Bioconductor 공식 페이지를 우선 확인합니다.

CRAN 패키지 예시: ggplot2

ggplot2 in r로 검색하면 Package ggplot2 - CRAN - R Project라는 공식 결과를 찾을 수 있습니다. 주소가 cran.r-project.org인지 확인합니다.

Bioconductor 패키지 예시: GEOquery

GEOquery in r로 검색하면 GEOquery package라는 Bioconductor 공식 결과를 찾을 수 있습니다. 주소가 bioconductor.org인지 확인합니다.

Bioconductor 패키지 페이지에서 확인할 것

  1. 페이지 상단의 Bioconductor version을 확인합니다.
  2. Installation의 To install this package, start R (version "x.x") 문장에서 요구하는 R 버전을 확인합니다.
  3. 설치 코드에서 정확한 package 이름을 확인합니다.
  4. 현재 R 버전은 RStudio Console에서 R.version.string으로 확인합니다.

페이지의 R 버전과 내 R 버전이 다를 때

패키지 페이지 아래의 appropriate Bioconductor release 링크를 이용하면 R과 Bioconductor release의 대응 관계를 확인할 수 있습니다.

오래된 package 파일을 임의로 직접 내려받아 설치하지 않습니다. 먼저 BiocManager::version()으로 현재 환경을 확인하고 BiocManager::install("GEOquery")를 실행합니다. 현재 R이 너무 오래되었거나 해당 release와 맞지 않을 때는 공식 대응표를 보고 R 업데이트 또는 호환되는 Bioconductor release 사용을 결정합니다. 
# 현재 R 버전
R.version.string

# BiocManager가 없다면 먼저 설치
if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}

# 현재 R에 연결된 Bioconductor 버전
BiocManager::version()

# 설치 상태와 버전 혼합 여부 점검
BiocManager::valid()

Bioconductor는 생물학적 데이터를 정확하고 재현 가능하게 분석하기 위한 오픈소스 프로젝트입니다. R과 Bioconductor의 버전 호환성을 관리하기 위해 공식적으로 BiocManager::install() 사용을 권장합니다.

버전 번호를 코드에 고정하지 않습니다. BiocManager::install()이 현재 설치된 R에 맞는 정식 Bioconductor 버전을 자동으로 선택하게 합니다.

9패키지 설치와 불러오기

CRAN 패키지 설치

11종합 실습 문제

아래 metadata를 새 R Script에 입력한 다음, 먼저 정답을 보지 않고 문제를 해결해 보세요. 

sample_info <- data.frame(
  sample_id = paste0("GSM00", 1:8),
  group = c("Control", "Control", "Control", "Control",
            "Disease", "Disease", "Disease", "Disease"),
  sex = c("F", "M", "F", "M", "F", "M", "F", "M"),
  age = c(41, 38, 45, 52, 49, 55, 61, 44),
  marker_expression = c(5.2, 4.8, 5.5, 5.0, 7.1, 6.8, 7.5, 6.2)
)

문제 1. 데이터 구조 확인

전체 샘플 수, 변수 수, 열 이름과 각 열의 자료형을 확인하세요.

문제 2. 단일 조건 추출

group이 Disease인 샘플만 추출하여 disease_info에 저장하세요.

문제 3. 복합 조건 추출

Disease 그룹이면서 여성인 샘플의 sample_id, age, marker_expression만 추출하세요.

문제 4. 연령 조건

50세 이상인 샘플은 몇 명인지 계산하고, 해당 샘플 전체 정보를 출력하세요.

문제 5. 그룹별 계산

Disease 그룹의 평균 연령과 Control·Disease별 평균 marker expression을 계산하세요.

문제 6. 새로운 변수 만들기

marker_expression >= 7이면 High, 그렇지 않으면 Low인 marker_status 열을 추가하고 그룹별 빈도를 확인하세요.
